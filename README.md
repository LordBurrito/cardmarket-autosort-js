# cardmarket-autosort-js

A Tampermonkey userscript to enhance browsing on Cardmarket.com for Magic: The Gathering.

## Description

This userscript automatically improves the browsing experience on Cardmarket's Magic singles pages:

- **On set pages**: Automatically switches to gallery view and sorts by price descending (highest first).
- **On individual card pages**: Adds floating action buttons to quickly filter for UK sellers, English listings or foil cards.
- **On sealed product pages** (booster boxes, boosters, decks, and so on): Adds the same UK sellers and English filters. The foil toggle is omitted because sealed products are never foil.

## Features

- Automatic sorting and view mode on set pages
- Toggle buttons for UK sellers (🇬🇧), English listings (EN) and foils (⭐) on card detail pages
- Toggle buttons for UK sellers (🇬🇧) and English listings (EN) on sealed product pages
- Non-intrusive floating UI elements

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) browser extension.
2. Click [here](https://raw.githubusercontent.com/LordBurrito/cardmarket-autosort-js/main/cardmarket-auto-sort.user.js) to install the script directly.
3. The script will automatically update from this repository.

## Usage

- Visit any Magic singles page on Cardmarket.com (e.g., https://www.cardmarket.com/en/Magic/Products/Singles/Time-Spiral/Mogg-War-Marshal)
- Or any sealed product page (e.g., https://www.cardmarket.com/en/Magic/Products/Booster-Boxes/The-Hobbit-Collector-Booster-Box)
- On set pages, the view will automatically switch to gallery mode sorted by price.
- On card and sealed product pages, use the floating buttons in the bottom-right to toggle filters.
